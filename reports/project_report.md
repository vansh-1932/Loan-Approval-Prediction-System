# Loan Approval Prediction System

## Objective
Predict whether a loan application will be approved.

## Dataset
Loan Prediction Dataset

## Models Used
1. Logistic Regression
2. Random Forest

## Feature Engineering
- TotalIncome
- LoanIncomeRatio
- LogIncome

## Results

| Model | Accuracy |
|---------|---------|
| Logistic Regression | 78.86% |
| Random Forest | 80.49% |

## Conclusion
Random Forest performed best with 80.49% accuracy.
